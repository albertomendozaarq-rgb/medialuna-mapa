# Módulos compartidos

Cada subcarpeta contiene `modelo.glb` y `ficha.json`. El script `scripts/publicar_modulos.py` recibe los paquetes `.mlmod` exportados por el taller, crea estas carpetas y actualiza `catalogo/manifest.json`.

No subir aquí archivos `.skp`, copias `.skb` ni archivos originales sin optimizar. Conserva los originales de SketchUp fuera del sitio. Los GLB deben contener sus texturas, usar metros y representar un objeto completo.

Los módulos publicados aparecen en **Mis módulos** al recargar la página. El taller también permite retirarlos de tu catálogo local sin borrar las copias colocadas en el mapa.
